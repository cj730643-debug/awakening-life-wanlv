# 《觉醒人生：万律世界》1000条有联系事件库 V1.0

> **用途**：网页人生模拟器事件数据库。
> 
> **设计原则**：1000条事件不是孤立文本，而是由主线、分支、回收、异常和轮回互相连接。每个事件都有前置事件与后续事件；部分关键节点会跳转到其他事件链，形成真正的因果网络。

## 一、事件结构

- **E0001～E1000**：唯一事件ID
- **主线**：同一章节默认顺序推进
- **分支**：关键事件可跳转到其他章节
- **回收**：后期事件会重新调用早期人物、选择、秘密、债务和线索
- **异常**：天赋满足特殊条件时，可以把普通事件重新解释成万律事件
- **终局**：死亡并不代表事件链结束，最终回到下一世入口

## 四、核心事件连接说明

### 1. 童年秘密链

E0018 → E0051 → E0101 → E0150 → E0460 → E0901

童年照片、硬币、旧朋友和研究线索不会在单次事件结束后消失，而会在成年后重新出现。

### 2. 恋爱—家庭—下一代链

E109 → E351 → E365 → E401 → E760 → E800 → E950

恋爱选择会影响婚姻，婚姻影响家庭，家庭影响子女；子女又会把前代未解决的规则问题带入下一阶段。

### 3. 事业—财富—名望链

E214 → E310 → E267 → E401 → E432 → E551

职业成功会制造财富，财富改变关系，名望又会让异常事件从私人层面扩散到社会层面。

### 4. 异常规则链

E157 → E901 → E910 → E930 → E246 → E950 → E995 → E1000

异常事件不是独立剧情，而是普通人生事件在天赋规则影响下产生的特殊解释。

### 5. 因果回收链

早年帮助、拒绝、借债、恋爱、错误、承诺和选择，都可能在E0800～E0950区间被重新回收。

### 6. 终局轮回

E0951～E1000负责把当前人生的因果、天赋冲突和死亡条件统一收束，并将角色重新送入下一世。

## 五、事件引擎建议

```text
事件触发
  ↓
检查年龄 / 属性 / 家庭 / 财富 / 人际 / 已发生事件
  ↓
检查玩家拥有的天赋规则
  ↓
普通事件是否被天赋改写？
  ├─ 否 → 按普通结果结算
  └─ 是 → 重新解释事件
              ↓
        检查第二条及以上规则
              ↓
        规则冲突 / 偷换概念 / 条件同时成立
              ↓
        生成异常事件或隐藏天赋
              ↓
        记录新的因果节点
              ↓
        解锁后续事件
```

## 六、关键原则

1. **事件不能只看当前年份**：过去发生过什么，会改变未来事件。
2. **人物必须持续存在**：朋友、恋人、父母、孩子、敌人和贵人都拥有自己的生命周期。
3. **选择必须留下后果**：玩家没有主动操作，但天赋、属性和随机事件会共同决定角色的选择。
4. **普通事件可以被天赋改写**：同一事件在不同天赋组合下可以产生完全不同的结果。
5. **异常事件必须有来源**：不能凭空出现，必须能追溯到某条天赋、某次选择或某个历史事件。
6. **死亡不是数据库终点**：死亡事件会把因果和天赋状态带入下一世。
7. **同一事件可以重复出现，但解释必须不同**：例如“朋友借钱”第二次发生时，可能变成债务回收、规则异常或前世因果。
