# 觉醒人生：万律世界

9:16竖屏中文网页人生模拟游戏，基于 [VickScarlet/remake（原 lifeRestart）](https://github.com/VickScarlet/remake) 的模拟核心改造。

创建人物并分配30点属性后，人生由系统自动推进。第一世没有天赋；死亡后从三个随机天赋中选一个，已获得的天赋永久保留。规则冲突、因果反馈与协同会生成隐藏天赋。

## 当前功能

- 七项初始属性，每项1～10，合计30。
- 自动成长、教育、工作、家庭、世界变化与有原因的死亡。
- 100个基础天赋、20种已测试的规则组合。
- 独立规则关系检测，支持未知天赋ID组成的关系环。
- 人生报告、轮回档案、天赋和悖论图鉴、世界历史。
- Seed复现，本地存档恢复、导入与导出，正确保存并显示无穷值 `∞`。
- 9:16竖屏界面，底部三个入口，单文件离线运行。

这是可玩原型。规则引擎支持当前声明的规则类型，并不是任意数学公式的通用求解器。测试中的界面检查是DOM交互合同检查，未代替真实浏览器视觉验收。

## 本地开发

需要 Node.js 24.3或更高版本，无需安装第三方运行依赖。

```sh
npm run build
npm test
npm run dev
```

- `dist/index.html`：网页发布入口。
- `dist/Awakening_Life_Wanlv.html`：可直接双击打开的单文件游戏。
- 开发服务：`http://127.0.0.1:5173`。修改源码后自动构建，刷新网页即可查看。

## 修改哪里

| 修改内容 | 源文件 |
| --- | --- |
| 页面和交互 | `src/app.js` |
| 9:16布局、字体、颜色 | `src/style.css` |
| 天赋与隐藏效果定义 | `src/catalog.mjs` |
| 规则关系检测 | `src/rules.js` |
| 人生、世界、事件与轮回流程 | `src/life.js` |
| 继承自上游的模拟基础 | `packages/core/src/` |

`dist/`、`data/`、`src/data.js` 是构建产物，不要直接编辑。构建会按类别生成天赋JSON，并打包为完全本地运行的HTML。

## GitHub与网页同步

工作流位于 `.github/workflows/pages.yml`：

1. 修改源码并提交到 `main`。
2. GitHub Actions构建HTML并执行测试。
3. 测试通过后自动部署至GitHub Pages。
4. 在线地址保持不变，刷新网页即可看到新版本。测试失败时不会发布。

首次部署需在仓库 **Settings → Pages → Source** 中选择 **GitHub Actions**。实际线上地址以工作流的部署结果为准。

发布后的代码会随GitHub更新；玩家存档仍保存在各自浏览器中，不会同步到GitHub。离线HTML和线上网页属于不同来源，换用线上版时可通过存档导出、导入继续游戏。

## 长期玩法边界

- 未拥有的基础天赋不足三个时，候选可包含已拥有天赋；重复觉醒形成共鸣层级，同一轮三个候选互不重复。
- 不死或超长寿角色不会被强制判死，每200年进入一个观察节点，可继续观察。
- 完整复现需要相同Seed、创建属性、觉醒选择序列与数据版本。
- 最多保留1000份人生摘要及最近30份完整轨迹，控制本地存档体积。
